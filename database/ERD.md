# Aurelia Hotels Database ERD

## Entities

- Hotels
- Rooms
- Guests
- Reservations
- Staff
- Recovery_Requests
- Room_Transfers
- Compensations

## Relationships

- One Hotel has many Rooms.
- One Hotel has many Staff members.
- One Guest can have many Reservations.
- One Reservation can have many Recovery Requests.
- One Recovery Request can have many Compensations.
- One Recovery Request can have many Room Transfers.
